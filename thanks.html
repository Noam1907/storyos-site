Twenty minutes, start to finish

  1. Unzip it anywhere you keep work. It is a folder, not an installer.
  2. Open it in the Claude desktop app. Go to the Code tab at the top, choose Local, click Select folder, and pick the StoryOS folder itself, the one holding CLAUDE.md. That is the whole setup.
  3. On Windows, install Git first. Free, five clicks, from git-scm.com. Claude will not open a folder on Windows without it, and you never have to open Git yourself. Most Macs already have it.
  4. Say hello. It greets you on the first run, asks what you sell and to whom, and builds from there. You are not configuring anything by hand.
