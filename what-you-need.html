What you need to run this.

Every line here is a requirement, not a recommendation. Read it before you pay, not after.

$20/MO
A paid Claude plan
Pro or above. The free tier won’t work, because it cannot open the Code tab StoryOS runs in. This is paid to Anthropic, not to us, and it is not included in the $79.
FREE
The Claude desktop app
Mac or Windows, from claude.ai/download. The browser version can’t read a folder on your computer, so it cannot run the kit.
FREE
Git, on Windows only
One download, five clicks, from git-scm.com. Claude will not open a folder on Windows without it. You never open it or type a command into it. Most Macs already have it.
FREE
A local folder
Not inside iCloud Drive, Dropbox or OneDrive. On a Mac this catches people: if iCloud Drive is syncing your Desktop and Documents, then your Desktop is a cloud folder. Your home folder is safe.
20 MIN
To install
Download, unzip, point Claude at the folder, click Accept once. No code, no command line, no config file to edit.
YOURS
To load your company brain
This is the work, and it’s yours. Until it is done, every asset it writes is about the fictional demo company that ships inside, not about you. How long it takes depends on what you already have written down: you can start with a link to your site, two things that sound like you and one deal you remember well, then sharpen it every time you run a play. A five day guide walks the thorough version. Nobody can do this part for you, and any seller who says otherwise is selling you the demo.
OPTIONAL
Obsidian
Free. It turns the kit from loose files into a clean workspace. Any text editor works instead.
